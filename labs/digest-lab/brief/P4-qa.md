# P4 —— 只读读本答题（在 `RichLethe-lab-qa` 那个项目里新开一个对话贴）

那个项目里只有一个文件可读，它想读别的也读不到。**这是判据的一部分，不是巧合。**

```
读 design/digest/stamina.md，然后回答 qa/questions.md 里的全部问题。

规矩：
- 每题先写答案，再写依据（引读本里的哪一节、哪一句）
- 读本里没说的，写「读本没说」。不许猜，不许用常识补
- 不要读别的文件，也不要问我
```

**对照组**（`--mode gdd` 生成的项目）把第一行换成 `读 design/gdd/stamina.md`，其余一样。

答完把整段存到 `runs/<run-id>/qa.md`，按 `qa/key.md` 批。
