# 跑 V1 —— 引擎换 Codex，其余跟 B0 一样

跑 **2 次**，run-id：`r04-V1-codex-main-<月日>a`、`r05-V1-codex-main-<月日>b`。
**先跑完 B0 三次再跑这组** —— 没有噪声下限，V1 的差异没法判。

跟 B0 只差一件事：写 GDD 那一步用 Codex。**评审和答题照旧用 Claude** ——
判官要固定，不然量到的是两个判官的差，不是两个写手的差。

## 一、前提

- Codex 要用户自己装。顶栏药丸点开，引擎那一栏 Codex 显示成「没装」或「装了但起不来」都先解决：
  `npm i -g @openai/codex`，然后在顶栏账号浮层里给 Codex 登录一次
- 铺项目、切本地模式、「我自己按」跟 `RUN-B0.md` 第一、二节一样

## 二、引擎

顶栏药丸 → 引擎选 **Codex**。**先切引擎再开新对话**（换引擎会另起一段）。模型名记进 notes。

## 三、写 GDD —— 跟 B0 不一样的四处

1. 左栏 **+ 开新对话**，贴 B0 同一行：
   ```
   /game-studio-core:design-system 体力（文件名用 stamina.md）
   ```
   **它认不认这条斜杠命令，本身就是要看的。** 不认（回了一句「这是什么」或者当成普通话聊）
   就记进 notes，再贴：
   ```
   用 game-studio-core 的 design-system 技能给「体力」写 GDD，文件名用 stamina.md
   ```
2. **Codex 不弹「想问几个问题」那种卡。** 它会把问题写在回复里、等你打字。
   照 `answers.md` 的选择**打字回答**（「就这么写」「通过」「Stop here」…）。它一次问好几个就一次答完
3. **读文件它不问**，只有写 / 改文件会弹审批卡 → **批准**。
   所以要看它读没读 `.claude/rules/design-docs.md` 和 GDD 模板，得盯着转录里的过程行
   （设置 → 「对话里的过程」要摆出来）—— 读了哪些文件记进 notes。这是 V1 最要紧的观察
4. **它不报花费。** 记开始和结束时间，RUNLOG 花费那格写 `—`，不许填 0

其余（记它选了什么、确认两个文件都在）跟 B0 一样。

## 四、评审前把引擎切回 Claude

顶栏药丸 → **Claude** → 左栏 **+ 开新对话** → 贴 B0 那一行评审命令。之后跟 B0 一样。
