# 读本实验室 —— 运行记录

一行一次。**没写进这张表的跑，等于没跑。**

列的意思：

- **run-id**：`r<两位序号>-<组>-<引擎>-<执笔>-<月日><字母>`，例 `r01-B0-claude-main-0916a`
- **变量**：这次跟基线不同的那一个（基线写 `—`）
- **技能版本**：跑的时候 harness 的短 SHA（`git rev-parse --short HEAD`）
- **红 / 黄**：`lint.json` 里的条数
- **图**：mermaid + svg 张数，`docshot` 报「画出来了」的张数（例 `3/3`）
- **问答**：讲错 / 没说 / 理解性 8 题得分（例 `1 / 3 / 6`）
- **评审**：`/design-review` 的 verdict
- **花费**：客户端顶栏读数；Codex 不报，写 `—`，时间照记
- **一句话**：跑的人在客户端里读完读本的那句话。**这一格不许空**
