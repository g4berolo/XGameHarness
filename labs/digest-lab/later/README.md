# 暂时不用的那一半

2026-09-16 用户把判据收窄成一句话：**开发人员在客户端里看读本，能不能一下子懂，好不好看。**
GDD 准不准、读本讲错没讲错、评审怎么说，这轮不管。

这里放的是为「准不准」准备的东西，留着以后用：

- `qa/` —— 二十道只读读本答题的题目和答案
- `P2-write-digest.md` —— 单独跑 `/write-digest` 那条路（V3）
- `P3-design-review.md` —— 让 `/design-review` 评一次
- `P4-qa.md` —— 答题的提示词

`make-project.mjs --qa` 那个模式对应的就是这里的题，也一并留着。
