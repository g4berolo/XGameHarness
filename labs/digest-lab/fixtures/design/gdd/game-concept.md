# Game Concept: 山脊（代号）

*Created: 2026-09-16*
*Status: Draft*

> ⚠ 这是**读本实验室的假游戏**（`labs/digest-lab/`），只用来测 harness 的技能和子 agent。
> 它故意做得小：四个系统、三根支柱、没有引擎细节。不要把它当成真项目扩写。

---

## Elevator Pitch

> 一款第三人称的山地冒险：你是个送信人，要翻过一座没有路的山，把信送到山那头。
> 山上没有敌人，只有崖壁、风、河和你的一圈体力。每一面崖壁都是一道选择题：绕、爬，还是滑过去。

---

## Core Identity

| Aspect | Detail |
| ---- | ---- |
| **Genre** | 开放地形的攀爬冒险（单机） |
| **Platform** | PC |
| **Target Audience** | 喜欢自己选路线、不喜欢被战斗打断的玩家 |
| **Player Count** | Single-player |
| **Session Length** | 一次 20–40 分钟，翻过一段山脊 |
| **Monetization** | 买断制 |
| **Comparable Titles** | 《塞尔达传说：旷野之息》的攀爬与滑翔、《A Short Hike》的轻松登山 |

---

## Core Fantasy

你不是战士，是一个**看着山、盘算路线、然后把自己送上去的人**。
爬到一半体力见底那一秒的心跳，和翻上崖顶回头看来路的那口气，是这个游戏要给的两种感受。

---

## Core Loop

1. **看地形**：站在一处，看清前方是崖壁、斜坡、河还是峡谷
2. **选路线**：绕远路走上去（不费体力，费时间）、直接爬（费体力，最快）、或者从高处滑翔过去（费一点体力，要有落差）
3. **管体力**：爬的时候盯着那一圈，估算够不够；不够就中途找落脚点歇一歇
4. **到了 / 掉了**：翻上去继续；掉下去不会死，但会掉回下面，丢掉刚才爬的高度
5. **补给**：路上捡到的果子、路边生火做的饭，吃了回体力，有的还能临时把那一圈变大

一次 session 是一段山脊：从一个营地到下一个营地。

## Pillars

| # | 支柱 | 一句话 | 它约束什么 |
|---|---|---|---|
| P1 | **每一面崖壁都是一道选择题** | 绕、爬、滑，三条路都要真的可选，不能有一条永远最优 | 体力和地形要一起调，让「爬」有时候是错的 |
| P2 | **资源看得见、算得清** | 玩家随时看得到自己还剩多少体力，没有暗数字 | 所有消耗和回复都要在屏幕上可读 |
| P3 | **掉下去不致死，但会丢进度** | 失败的代价是高度，不是生命 | 没有生命值；「摔」只把玩家送回下面 |

---

## Systems（只有这四个）

| # | 系统 | 一句话 |
|---|---|---|
| 1 | 角色移动 | 走、跑、游、爬、滑翔五种移动方式，以及它们之间怎么切换 |
| 2 | 体力 | 那一圈体力怎么扣、怎么回、扣光了会怎样 |
| 3 | 攀爬与滑翔 | 贴墙爬和张伞滑的具体规则，两者都靠体力 |
| 4 | 食物与增益 | 吃东西回体力、临时加大体力圈 |
