## 独立看图验收

使用 `examples/crate.py` 与 `examples/crate-brief.md` 制作补给箱，由独立审查 agent 实际查看六张预览。
首轮指出侧把手悬空，修正为连接座与横杆，并补充另一侧透视图；再次审查结论为 **PASS（示例 brief 范围）**。

最终对象数 18、三角面 1944 / 3000、材质 3 / 3；箱盖宽 1 m，总宽约 1.2 m，底面 z=0。
GLB 与 FBX 回读均为 18 个网格、1944 个三角面，包围盒在 0.0001 容差内匹配。

**未验证**：UE 内实际导入、导出前后逐像素材质等价、其他操作系统或 Blender 版本。
来源为本地脚本建模，未使用生成式 3D 服务或外部模型；该测试不代表复杂角色、绑定、动画已经验收。

## 接入决定

1. 建模前固定参考图、尺寸、预算、来源和验收 brief；缺图时明确采用文字 brief，不能假称有参考。
2. 第一版提供 `blender-artist` 与独立 `asset-reviewer`。宿主无法委派时必须标记未独立审查。
3. MCP 和 CLI 共用执行层；实时窗口只操作专用副本，批量作业逐次保存脚本、参数、日志和结果。
4. modeled / imported / generated 分别记来源；外部素材库及生成服务均为可选项，不随包要求密钥。

当前 Codex 插件会把相对 cwd 定位到安装根，但不会展开 Claude 的插件根变量；Claude 则会展开。
启动器据此兼容两者，且保留无 MCP 宿主的 CLI 入口。XGameHarnessUI 的账号隔离和项目启用规则见
[连接说明](connection.md)，不能把用户级 CLI 安装等同于所有客户端项目都已启用。
