# 资产需求

- 名称 / 用途 / 目标引擎：
- 输入 .blend（新建则无）：
- 参考图片路径及需要匹配的特征：
- 已知尺寸、单位、轴向、原点位置：
- 推测部分 / 待确认部分：
- 风格 / 目标屏幕占比：
- 三角面预算（未知写未知）：
- 材质数量 / 贴图规格 / UV 要求：
- 碰撞 / LOD / 骨骼动画要求（不适用则注明）：
- 来源模式：modeled / imported / generated
- 可用素材与许可 / 获准使用的生成服务：
- 输出格式：blend + glb 或 fbx + 五视图
- 验收重点：front / side / back / top / hero 与原始参考
- 默认修正预算：3 轮；仍未通过则报告剩余问题
